# Triple Mac E Construction

A complete static website for Triple Mac E Construction, built with vanilla HTML, CSS and JavaScript.

## Deploy

Upload this folder to GitHub Pages, Netlify, Vercel, or any static host. No build step, framework, server, API, or environment variables are required. Open `index.html` locally to preview it.

The quote form opens a pre-filled WhatsApp enquiry to `+27 78 440 2685`; replace the asset in `assets/images/` with genuine company project imagery when available.
